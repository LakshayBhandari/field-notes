How to add a chapter

This is a plain static site — no build step. The phrases How to add a chapter and How to add a theme below describe the multi-page workflow.

How to add a chapter

  1. Copy ch-TEMPLATE.html to ch-NAME.html (lowercase, hyphenated, e.g. ch-csrf.html).
  2. Edit it: set the <title> and <h1>, then write the explanation and the ⚠️/🔄 callouts (the template already contains the callout skeletons).
  3. Wire navigation: the ← Home link already points to index.html. Set this page's ‹ Prev to the chapter that was previously last; set that previously-last chapter's Next › to this new page; set or delete this page's Next › (delete if this is now the last chapter).
  4. Add one card to the .chapter-grid in index.html:
<a class="chapter-card" href="ch-NAME.html"><div class="ct">Title</div><div class="cd">One line.</div></a>
  1. Run python3 ../tooling/codex_check.py (from codex/site/) — it must print PASS (it checks the new page's shell, relative-only links, callout structure, and that the index card resolves).

How to add a theme

Themes live in assets/codex.css.

  1. Add a palette block next to the existing ones — copy every variable from the :root[data-theme="light"] block and retune the values:
:root[data-theme="NAME"] { --bg: …; --text: …; /* …all 23 vars from the light block… */ }
  1. Add a matching option to the theme <select>. It is part of every page's nav bar, so add the option to ch-TEMPLATE.html and to each existing page's <select> (the theme list is duplicated per page in a static site — keep the theme count small):
<option value="NAME">Label</option>
